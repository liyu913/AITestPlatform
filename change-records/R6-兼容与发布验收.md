### 并发问题（已修复）

首轮窗口在 4 并发下触发 MySQL 死锁：

```
(1213, 'Deadlock found when trying to get lock')
UPDATE test_cycles SET updated_at=... WHERE test_cycles.id = ...
```

原因：每次运行回写尝试时都更新批次行，同一批次的并发运行在批次行与计划项/尝试行之间形成锁竞争。
修复：回写尝试不再触碰共享的批次行（`cycle.updated_at` 不再随每次运行更新），批次统计仍由计划项与尝试计算。
修复后 4 并发跑完 200 次零死锁、零失败。该行为变更已由全量测试覆盖。
