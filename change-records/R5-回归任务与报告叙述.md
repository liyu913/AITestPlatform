# R5：回归任务与报告叙述

记录时间：2026-11-05。按计划 R5 完成「缺陷修复 → 回归批次 → 报告叙述」的闭环。

## 1. 回归任务

- `POST /projects/{id}/defects/regression-tasks`：
  - 入参：缺陷 ID 列表、批次名称、可选计划、目标构建、环境；
  - 自动收集所选缺陷关联的用例（去重），创建/复用测试计划与批次，生成计划项；
  - 批次项记录用例当前正式发布版本；缺陷 `regression_cycle_ids` 回写批次 ID；
  - 无关联用例返回 400，缺陷不存在返回 404。
- 前端：缺陷列表新增「创建回归任务」弹窗（多选缺陷、批次名称、修复构建），创建后跳转批次详情。

## 2. 报告叙述

迁移 `k1l2m3n4o5p6`：`test_cycle_reports` 增加 `narrative`、`narrative_config`。

- `POST /projects/{id}/reports/{report_id}/narrative`：
  - 按动作 `regression_report` 走四级解析（本次调用 → 动作绑定 → 项目默认 → 系统默认）；
  - 使用解析出的模型档案调用 LLM，把统计、风险、目标构建写入提示词；
  - 结果与配置快照（action/mode/source/model/skill）保存到报告行，返回完整报告；
  - 未配置可用模型返回 400，LLM 调用失败返回 502（不静默伪造文本）。
- 前端：报告详情新增「报告叙述」卡片，展示叙述与「生成配置」，支持重新生成。

## 3. 前后证据

## 5. 说明与遗留

| 项 | 说明 |
| --- | --- |
| 真机 LLM 调用失败 | 当前环境模型网关返回 HTTP 400，接口按设计返回 502；UI 验证使用预置叙述 |
| 回归任务未自动开始 | 新建批次为 `draft`，仍需就绪检查与开始（R3 闸门） |
| 回归范围选择 | 当前按缺陷关联用例自动收集，未支持手工增删范围 |
| 报告对比不含叙述 | 版本对比仍只比较指标/风险/覆盖 |
