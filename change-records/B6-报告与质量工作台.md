## 2. 统计口径（与计划一致）

| 指标 | 定义 |
| --- | --- |
| 选定计划项 | 批次内全部计划项 |
| 通过率 | `通过 / (通过 + 失败)`；分母为 0 时显示「不适用」 |
| 完成比例 | `(通过 + 失败) / 选定计划项` |
| 阻塞 / 未执行 / 运行中 / 跳过 | 分别展示，互不重叠：`未执行 = 总数 - 通过 - 失败 - 阻塞 - 运行中 - 跳过` |
| 重试后通过 | 最终通过但曾失败的项，保留首次失败尝试序号与摘要 |
| 不稳定 | 同一项同时出现过通过和失败尝试 |

需求覆盖标注覆盖方式：

- **用例关联覆盖**：需求关联了用例；
- **规则覆盖**：需求只有验收规则、没有用例；
- **无覆盖**：两者都缺。

## 3. 快照内容

每次生成写入 `test_cycle_reports.snapshot_json`：批次配置（计划、目标构建、环境快照、凭据引用、数据说明）、范围与结果分布、指标、计划项固定版本与当前版本漂移、需求覆盖、重试/不稳定、关联缺陷、遗留风险与生成时间。

报告不可变：再次生成产生 `revision+1`，旧报告内容不随后续编辑变化。

### 风险清单

| code | 触发 |
| --- | --- |
| `empty_scope` | 批次没有计划项 |
| `untested` / `running` / `blocked` / `failed` / `skipped` | 对应结果项 > 0 |
| `flaky_retry` | 存在重试后通过项 |
| `requirement_blind` | 需求覆盖存在盲区 |
| `open_defects` | 关联缺陷未关闭 |
| `missing_fix_build` | 已修复缺陷缺修复构建 |
| `case_version_drift` | 计划项固定的用例版本与当前版本不一致 |

## 4. 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/projects/{pid}/reports/cycles/{cycle_id}` | 生成新快照（revision 自增） |
| GET | `/projects/{pid}/reports/cycles/{cycle_id}` | 批次报告历史（倒序） |
| GET | `/projects/{pid}/reports` | 项目报告列表 |
| GET | `/projects/{pid}/reports/{report_id}` | 报告详情（含完整快照） |
| GET | `/projects/{pid}/reports/{report_id}/export?format=md|xlsx` | 导出 |

Excel 导出含「概览 / 需求覆盖 / 重试与不稳定 / 遗留风险」四张表。
