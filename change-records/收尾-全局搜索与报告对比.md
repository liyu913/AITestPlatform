# 收尾：全局搜索与报告版本对比

记录时间：2026-11-05。补齐计划里顶部导航的「搜索」入口，以及报告的历史对比能力。

## 1. 项目内搜索

### 后端

`GET /projects/{pid}/search?q=...`（`backend/app/api/project/search.py`）：

| 来源 | 匹配字段 | 跳转 |
| --- | --- | --- |
| 需求 | 标题、正文 | `requirements?requirement={id}` |
| 功能用例 | 标题 | `test-cases?case={id}` |
| 计划 | 名称 | `test-plans/{id}` |
| 批次 | 名称 | `cycles/{id}` |
| 缺陷 | 标题 | `defects?defect={id}` |
| 接口用例 | 名称 | `api-cases?caseId={id}` |
| UI 用例 | 名称 | `ui-cases?case={id}` |

- 每组最多 5 条，按更新时间倒序；为空的分组不返回；
- `%`/`_`/`\` 做转义，输入 `100%` 不会匹配全部记录；
- 仅项目成员可查询，跨项目返回 403/404；
- 空查询返回空结果，不做全表扫描。

### 前端

顶部栏新增搜索框（[ProjectSearch.tsx](../frontend/src/components/ProjectSearch.tsx)）：输入 250ms 防抖后分组展示结果（标题 + 副标题），选中即跳转到对应记录。

列表页补齐深链接：

| 页面 | 参数 | 行为 |
| --- | --- | --- |
| 用例管理 | `?case=ID` | 打开该用例编辑弹窗（缓存里没有则按 ID 拉取） |
| 需求管理 | `?requirement=ID` | 打开需求编辑弹窗 |
| 缺陷与回归 | `?defect=ID` | 打开缺陷详情抽屉（含证据） |
| UI 用例 | `?case=ID` | 打开 UI 用例编辑弹窗 |
| 接口用例 | `?caseId=ID` | 打开接口调试面板（原有能力） |

参数读取后从 URL 移除，刷新不会重复弹窗；切换项目会由 `ProjectShell` 重新挂载。

## 2. 报告版本对比

`GET /projects/{pid}/reports/{report_id}/compare?against={other_id}`：

- 默认对比同一批次的上一个 revision；
- 返回指标逐项 `上一版 / 当前 / 变化`（通过率、完成比例、通过/失败/阻塞等 11 项）；
- 返回新增风险、已消除风险；
- 返回覆盖发生变化的需求（用例数与覆盖率前后值）；
- 跨批次对比、与自身对比、无历史版本均返回 400。

前端报告详情页新增「对比历史版本」下拉，弹窗展示指标差值、风险增减与覆盖变化。
