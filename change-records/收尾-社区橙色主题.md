# 收尾：地瓜开发者社区风格主题

记录时间：2026-11-05。参考 https://developer.d-robotics.cc/ 的视觉语言，将平台前端从「Ink Cobalt」蓝色主题切换为社区橙色主题。

## 1. 取色来源

从社区站点样式表（`_next/static/css/*.css`）读取到的设计变量：

| 变量 | 值 | 用途 |
| --- | --- | --- |
| `--color-brand` / `--color-primary` | `#fe6702` | 主色（按钮、链接、选中态） |
| `--color-primary-hover` | `#f69452` | 悬停 |
| `--color-primary-active` | `#e15b02` | 按下 |
| `--color-primary-soft` | `rgba(254,103,2,.08)` | 选中背景 |
| `--color-canvas` | `#f5f9fd` | 页面画布 |
| `--color-surface` | `#ffffff` | 卡片/面板 |
| `--color-surface-muted` | `#f2f4f7` | 表头/次级块 |
| `--color-border` / `--color-divider` | `#edeff2` / `#e6e8eb` | 描边 |
| `--color-text-primary/secondary/muted` | `#1a1d26` / `#60636b` / `#91959e` | 文字 |
| `--radius` | `10px` | 控件圆角 |
| 卡片阴影 | `0 6px 8px #1a1d2606` | 轻量悬浮感 |

字体采用 `PingFang SC / Microsoft YaHei` 栈。

## 2. 改动

| 文件 | 变更 |
| --- | --- |
| `frontend/src/theme/tokens.ts` | 调色板与圆角、控件高度、字体 |
| `frontend/src/index.css` | `:root` 变量；外壳样式：顶栏（56px、半透明毛玻璃、品牌橙色渐变方块）、侧栏（232px、10px 圆角菜单、橙色选中态）、卡片（12px 圆角 + 轻阴影）、登录页（暖橙渐变背景）、表头与焦点环 |
| `frontend/src/main.tsx` | antd 主题：主色/悬停/按下、链接色、圆角 10、控件高度 34、阴影由「全平」改为轻量分层；按钮主色带橙色投影 |

标签颜色保留语义（通过绿 / 失败红 / 阻塞黄），未强制改成橙色，避免状态不可辨。

## 4. 部署说明与限制

- **本次通过热替换 `dist` 到前端容器生效**：`docker cp dist/. <frontend>:/usr/share/nginx/html/`。
  原因是本机 Docker 守护进程配置了代理 `127.0.0.1:7890`，当前代理未启动，`build frontend` 拉不到
  `node:22-alpine`。容器重启后会回退到镜像内旧前端。
- 正式发布需在代理可用或基础镜像已缓存的环境执行：
  `docker compose ... build frontend && docker compose ... up -d --no-build frontend`。
- 当前只做了视觉层（颜色、圆角、阴影、字体、顶栏/侧栏/登录页）。如果希望进一步贴近社区的
  首页信息架构（横幅、灵感/技能卡片流、页脚），需要单独改版，不属于本次主题范围。

## 5. 品牌 Logo

- 使用用户提供的社区形象（橙色机器人）作为品牌 Logo，处理为透明底、紧凑裁切（211×256，`frontend/public/logo-ip.png`）。
- 顶栏：Logo 高 32px，位于「LY测试平台」文字前；登录页：高 44px，与品牌名同一行。

- 原始附件含 1px 左侧暗边与浅色背景，生成脚本按边缘 flood fill 去底后再裁切，避免白底方块。
- 截图：`logs/login-final2.png`、`logs/topbar-final2.png`。

## 6. 列表卡片按钮统一

需求卡片原本把 7 个操作铺成橙色文字链接；功能用例、UI 用例、接口用例、缺陷列表也有同类问题。统一改为「主操作 + 文字次操作 + ⋯ 菜单」：

- 只保留 3 个高频入口：`需求分析`（主按钮）、`AI 生成`、`编辑`（文字按钮）；
- 低频操作收进 `⋯` 菜单：预览附件（无附件时禁用）、生成测试计划、查看用例、删除需求（二次确认）；
- 「新建需求」按钮加 `+` 图标；主按钮投影由 `0 4px 10px .18` 收到 `0 2px 6px .16`，去掉明显光晕；
- 表格「操作」列宽度由 440 收到 260，与卡片共用同一套按钮。

验证：`tsc -b`、`vite build` 通过；在部署栈打开菜单确认禁用态与图标正常。截图：
`logs/req-actions-2.png`、`logs/req-menu2.png`。

### 统一覆盖范围

| 页面 | 保留在主操作区 | 收进 `⋯` 菜单 |
| --- | --- | --- |
| 需求管理 | 需求分析（主）、AI 生成、编辑 | 预览附件、生成测试计划、查看用例、删除 |
| 功能用例 | 自动化执行（主）、查看 UI 用例（有链接时）、编辑 | 查看步骤、版本/评审、删除 |
| UI 用例 | 执行（主）、编辑 | 删除 |
| 接口用例 | 执行（主）、调试 | 删除 |
| 缺陷与回归 | 详情（主）、复测、关闭/重新打开、编辑 | 状态历史、删除 |

删除操作一律改为二次确认弹窗（`modal.confirm`），不再用行内 `Popconfirm`；各表格操作列宽同步收紧。
